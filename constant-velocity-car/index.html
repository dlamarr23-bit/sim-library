How to use this simulation

  1. Tap masses in the Mass set tray to stack them on the car's platform. Use Remove top mass or Clear masses to change the load.
  2. Press Start to run the car. Each run lasts 10 seconds, and a tape flag drops at the front bumper every second.
  3. Watch the front bumper's position and the change in position (Δd) fill in the data table as the run plays.
  4. When the run finishes, it is saved to the Position vs time graph, so you can compare runs with different masses.
  5. Read the car's distance from the start line off the meter sticks on the track: each stick reads 0 to 100 cm before the next stick starts over at 0.
  6. Turn off Show speed readouts if you want to find the speed from the graph instead of reading it directly. Turn on Add measurement error to practice fitting a best-fit line to noisy data.
  7. Press Reset run to clear the current run and try again, or Clear saved runs to remove every saved line from the graph.
