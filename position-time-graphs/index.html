How to use this simulation
  1. Drag the student along the meter sticks to set a starting position, or click the scene and use the ← and → arrow keys.
  2. Press Start stopwatch to begin recording. Each run lasts 15 seconds, shown by the Stopwatch readout at the top.
  3. While recording, hold ← Toward or Away → (or the arrow keys) to walk the student, or drag them directly for full control.
  4. Watch the position-vs-time graph draw itself live, both on the small Chromebook screen and in the larger graph panel.
  5. To read the student's distance from the sensor off the meter sticks: meter stick 1 reads 0 to 100 cm. If the student has walked past the seam onto meter stick 2, that stick starts over at 0. Add the two totals together — all of meter stick 1 (100 cm) plus the reading on meter stick 2 — to get the total distance from the sensor.
  6. Try the Target graph to match menu, then move the student to match the dashed target line on the graph.
  7. Turn on Keep the last run to compare two runs on the same graph, or Model the sensor's 15 cm blind spot to see the gap a real sensor leaves when the student stands too close.
  8. Press Reset to clear the current run and try again. Use Copy data to copy your recorded time and position data for a spreadsheet.
